Iris Dataset Data Cleaning Project

Project Overview
This project focuses in checking and cleaning the Iris dataset using Python and Pandas.

Tools Used
1) Python
2) Pandas
3) PyCharm

Data Cleaning Tasks
1) Loaded the Iris datasets.
2) Checked dataset rows and columns.
3) Checked missing values.
4) Checked data types.
5) Checked unique species values.
6) Saved the dataset as cleaned_iris.csv.

Results
1) Missing values were checked.
2) Duplicates records were cheked.
3) data types were inspected.
4) Species values were inspected.

Output
The cleaned dataset is saved as data/cleaned_iris.csv.
